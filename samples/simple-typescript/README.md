# Setup

```sh
$ npm install
```

```sh
$ chmod +x main.ts
```

# Run

```sh
$ ./main.ts
```

Or: `$ npm start`

# Test

```sh
$ npm test
```

# Debugging

Launch the `tsx` option from the debugger panel (i.e. `CTRL + SHIFT + D`) to debug whatever `.ts` file is currently open: works for any file and tests too.
